# Motor direction test

Arduino IDEで `motor_direction_test.ino` を開き、ESP32-S3へ書き込む。
シリアルモニターは115200 baudに設定する。既存の自律走行コードとは別スケッチなので、電源投入時に勝手に往復動作を始めない。

安全のため、最初は車輪を浮かせて配線と停止動作を確認する。床上試験はPWM 60で行い、すぐ停止できるようにする。各指令は3秒後に自動停止する。

## Commands

| Command | Wheel | Raw direction |
|---|---|---|
| `1` | 左前 | + |
| `2` | 左前 | - |
| `3` | 後ろ | + |
| `4` | 後ろ | - |
| `5` | 右前 | + |
| `6` | 右前 | - |
| `r` | 3輪 | 全輪+ |
| `0` | 全輪 | 即時停止 |

コード上で正とする車輪の力方向は、左前=後ろ左、後ろ=右、右前=前左。各車輪についてraw `+`がこの方向なら `MOTOR_DIRECTION_SIGN=1`、raw `-`がこの方向なら `MOTOR_DIRECTION_SIGN=-1` とする。
